# Thesis Repository

This repo contains data, scripts, and figures for a project on biblical language in U.S. presidential speech.

It is a research workspace, so it is a mix of cleaned outputs, analysis scripts, and intermediate files.

## What is where

- `cleaned-results/`: the main cleaned datasets used for analysis.
- `data-visualizations/`: scripts for making plots and charts.
- `results/`: generated outputs, including figures, tables, and intermediate pipeline results.
- `scripts/`: the main data-processing and verse-extraction code.

## In short

Final data in `cleaned-results/`.

Figures in `results/figures/`.

Code that does the extraction and processing in `scripts/`.
